# Demo video script — SCRIPT ONLY. Video NOT recorded, NOT published.
Target: under 3 minutes (aim ~2:20 spoken). Public video required;
no third-party trademarks or copyrighted music.

On-screen line throughout: "Advisory only — not medical advice.
Demo data in this recording is marked as such."

## 0:00–0:20 — The problem (presenter, direct to camera)
"My neighbour is 78. Her doctor changed a prescription, and the
leaflet that came with it was written for a clinician, not for her.
She could not spell the generic name, so a text checker was no help
at all. This is ClearDose: a prescription, explained in plain language."

## 0:20–0:50 — Before (screen: typed checker, clinician label)
"Before: type the name exactly right, then read this label alone.
Long words, warnings in three different sections, and the other
drug's label says something different. That is the gap ClearDose
closes."

## 0:50–1:40 — After: explain + photo (screen: CLI/web demo, DEMO DATA banner visible)
"After: ClearDose shows ibuprofen's label under plain-language
headings, in the label's own words, with the section each excerpt came
from. Then the photo:
this is a synthetic demo label, not a real bottle. ClearDose reads
it, matches ibuprofen, and checks it against warfarin — both labels.
There is the flag, in the label's own words, from both directions.
ClearDose never says a combination is safe."

## 1:40–2:05 — Questions + limits (screen: pharmacist questions)
"And it hands her questions to take to her pharmacist — including
the flag, in plain words. If a label cannot be retrieved, ClearDose
says so and flags nothing. If no medicine is matched in a photo, it
does not guess."

## 2:05–2:20 — Close (presenter)
"ClearDose: built with the Strands Agents SDK, for the moment before
a new medicine is taken. Advisory only — ask your pharmacist first.
Thank you."
